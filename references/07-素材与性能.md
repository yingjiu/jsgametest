# 07 · 素材与性能

游戏跑在**安卓 WebView** 里（不是 Chrome 桌面），性能预算比 PC 紧得多。以下都是踩过坑的结论。

---

## 1. 素材

- 用**相对路径**引用（`cover.png`、`animals/rabbit.png`），平台已放开 `file://` 域互访；
- 想预加载就把路径写进 `manifest.assets`，再用 `DualArena.assets.load(ctx.assets, cb)`；
- **缺失必须能回落**：`assets.load` 失败会给你 `null`，此时用矢量/文字/色块顶上（硬性要求，别让游戏崩或空白）；
- 封面 `cover.png` 建议 **512×288**（16:9），会被列表卡片裁切显示；
- 图片别做超大尺寸：WebView 里 `drawImage` 大图的缩放开销很实在，按需缩到亚像素级尺寸。

```js
init: function (ctx) {
  DualArena.assets.load(ctx.assets, function (m) { /* m[url] = Image | null */ });
},
render: function (now, ctx, c) {
  var img = DualArena.assets.get("deer.png");
  if (img) c.drawImage(img, px - w/2, py - h/2, w, h);
  else { c.fillStyle = "#c98"; c.fillRect(px - w/2, py - h/2, w, h); }  // 回落
}
```

---

## 2. 【性能头号杀手】`shadowBlur`

移动端 WebView 里 `ctx.shadowBlur` 是**逐次高斯模糊**，7 个实体就足以把帧率砍到 20~30fps，
表现就是"画面不流畅"。**不要用它做光晕。**

替代方案（示例 `neonstars` 就是这么做的）：

```js
// 两层半透明同心圆，视觉接近光晕，开销极低
function glow(c, px, py, pr, col, alpha) {
  c.globalAlpha = alpha * 0.15; c.fillStyle = col;
  c.beginPath(); c.arc(px, py, pr * 2.1, 0, Math.PI * 2); c.fill();
  c.globalAlpha = alpha * 0.20;
  c.beginPath(); c.arc(px, py, pr * 1.5, 0, Math.PI * 2); c.fill();
  c.globalAlpha = alpha;
}
```

其它高开销项：大面积 `filter`、每帧 `createLinearGradient`、每帧 `getImageData`、超大 `font` 反复 `measureText`。

---

## 3. 快照体积（直接影响对端手感）

`serialize()` 每帧产出、被节流到 ~30Hz 跨桥下发。**体积过大会堆在网络线程上，对端一卡一卡。**

- 只放"影响胜负或对端渲染"的字段；
- 浮点 `toFixed(3~4)`，或先乘后取整；
- 用**数组下标**代替长字段名：`[x,y,r,type,hue,life]` 比 `{x,y,radius,kind,color,lifetime}` 小得多；
- 纯视觉粒子只同步最近少量（示例里限 14 个），其余由对端本地生成；
- 参考量级：一款 2~10 个实体的游戏，快照控制在**几百字节**内比较舒服。

---

## 4. 渲染

- 只画本机可见的：`if (!ctx.visible(x, y, r)) continue;`（分屏模式下能省掉一半绘制）；
- 背景别每帧重建复杂图形；静态层可以缓存到离屏 canvas；
- 帧循环由 SDK 的 rAF 驱动，**不要**自己再起 `setInterval` 做逻辑（会和 `tick` 打架）；
- 文字用系统字体，避免加载 web font（真机无网/体积都不划算）。

---

## 5. 音频

WebView 默认**不允许**在无用户交互前自动播放音频；且从 0 延迟与稳定性考虑，**建议不依赖音频**，
或只做"用户点触后播放"的短音效。目前平台未提供原生音效桥，重要反馈请用**视觉**表达（闪光/抖动/飘字）。

---

## 6. 体积与启动

- 单个游戏包建议 **< 3MB**（含素材），否则解包/加载变慢；
- 首屏尽量只做"建状态 + 画背景"，重活放到 `onStart` 之后；
- `init()` 里避免同步读取大文件/大量图片解码（会卡启动）。

---

## 7. 一份可直接抄的性能自检

- [ ] 没有 `shadowBlur` / `filter`
- [ ] `serialize()` 只含必要字段，浮点已压缩
- [ ] `render` 里对每个实体都做了 `ctx.visible` 判空
- [ ] 逻辑随机只在 `tick`/`init` 取，且用 `ctx.rng()`
- [ ] 没有自己起独立计时器推进逻辑
- [ ] `hud()` 返回值轻量（数组长度恒为 2）
